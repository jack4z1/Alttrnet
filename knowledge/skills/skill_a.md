# Skill A — Summarizing a Document

*Sample document for testing the ALTTRNET ingestion pipeline.*

## Purpose

This skill summarizes a long document into a short list of key points.

## When to use it

Use this skill when the user has a document and wants the main ideas
without reading everything.

## Steps

1. Read the document end to end once.
2. Identify the main topic of each section.
3. Write one sentence per section capturing its main point.
4. Merge related points and remove repetition.
5. Order the final points by importance.

## Constraints

- Keep the summary under ten sentences unless asked otherwise.
- Do not add facts that are not in the document.
- Prefer the document's own terminology when it is precise.
